# ADR-0009: Java 25 LTS

- Estado: Aceptada
- Fecha: 2026-10-29
- Decisiones relacionadas: D-01

## Contexto

El repositorio partía de Java 17. Spring Boot 4.1.2 admite Java 17 a 27.

## Decisión

Java 25 LTS (Temurin) en todos los servicios, en IntelliJ y en la CI (`actions/setup-java@v6`).

## Consecuencias

Versión LTS vigente durante todo el TFM.

## Alternativas descartadas

Java 17 (LTS anterior) o Java 21.
